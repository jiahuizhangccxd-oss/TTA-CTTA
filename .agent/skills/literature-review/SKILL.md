# Literature Review

## Purpose

Produce a source-grounded synthesis serving one research question.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the bounded review question, original
sources and any repository-local systematic/scoping-review protocol.

## Workflow

1. Identify which assumptions, mechanisms or findings must be compared.
2. Search relevant foundational, recent, closest, theoretical, benchmark and
   contradictory sources; use review articles to orient discovery, not replace
   original support.
3. Extract question, assumptions, method, result, limitation and exact relation
   for each source actually used.
4. Synthesize agreement, disagreement, non-comparability and unresolved gaps by
   shared scientific dimensions, not a study-by-study list.
5. Revise the requested section and only the bibliography/source records it needs.
   Follow required search/screening/flow documentation for an actual systematic
   review, not as a compulsory workflow for ordinary related work.

## Output

The requested synthesis, revised section or verified reference set, with source
findings distinct from author inference and unresolved access gaps explicit.

## Validation

Recheck used factual claims and citations against original passages. Abstract
omission, citation count and venue prestige do not establish a scientific gap.
Do not claim search completeness that the inspected sources cannot support.
