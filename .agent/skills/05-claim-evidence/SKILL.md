# 05 Claim Evidence

## Purpose

State the strongest conclusion justified by the actual evidence.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the exact claim, relevant proof,
valid completed results or original sources, local protocol and hypothesis history.

## Workflow

1. Identify claim type: theoretical, descriptive, performance, associational,
   mechanistic, causal, generalization, robustness, efficiency or design principle.
2. Match evidence to that claim, including the strongest counterexample or
   competing explanation. Inspect competitive baselines and treatment validity
   for empirical comparisons.
3. Separate fact, inference, exploratory finding and hypothesis; preserve H0-H3
   provenance. Separate outcome, mechanism and boundary evidence.
4. Retain, narrow, reject or leave the claim unresolved. Missing/invalid evidence
   is not automatically contradictory evidence; a valid negative result remains
   evidence. Do not select only favorable runs or reinterpret adverse evidence.
   For a staged study, report each hypothesis as Supported, Refuted or Inconclusive
   against its declared prediction. State the supported scope and unmet obligations;
   a gain on one dataset cannot erase failed replication or prove a mechanism.
   This is an interpretation, not a new record enum or an automatic writing gate.
5. Update only existing records made stale. For an explicit status request, use
   the existing research-loop status guidance without creating duplicate authority.

## Output

Permitted wording, exact support, provenance, scope and remaining evidence gap.
Use a claim-evidence table only when useful to the request, not a strength score.

## Validation

Trace each changed conclusion to its evidence. Check that implemented, executed,
verified and supported remain distinct, and that performance was not promoted to
mechanism, causality or universality.
