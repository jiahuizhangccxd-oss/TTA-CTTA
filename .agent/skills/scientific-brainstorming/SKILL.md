# Scientific Brainstorming

## Purpose

Identify genuine mechanism-distinct directions rather than naming or module
variants. Initialization does not approve a paper direction.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), known problem observations, relevant
prior sources, feasibility limits and existing candidate/author decisions.

## Workflow

1. Establish the actual failure, contradiction or unexplained boundary. If none
   is observed, keep it unknown, leave the front-runner unselected and identify
   the most informative evidence-gathering action.
2. Generate only supported distinct possibilities, at most four. Zero or one is
   valid. Stop when the next candidate repeats an existing mechanism.
3. For each, specify the changed scientific object, before/after principle,
   mechanism, prediction, nearest-neighbor delta or open search question,
   rejection condition, decisive test and scope.
4. Use M/P patterns only as optional search lenses, never labels required for
   novelty or promotion. Compare real alternatives without weighted scores.
5. Formalize at most one provisional front-runner with the strongest competing
   explanation and confound-isolating test. Use hypothesis-generation support
   only if needed. Preserve the author's separate approval authority.
6. Predeclare how null, contradictory or boundary-only outcomes revise, weaken or
   eliminate the direction; do not invent evidence to fill the card.

## Output

For candidate scanning, update the existing candidate workspace. For
`@初始化入口`, update the one-page core innovation card and only the intake or
candidate records that actually need change. No manuscript, code or run is implied.

## Validation

Check genuine mechanism differences, source support, falsifiability and approval
boundaries. A no-failure input must permit no selected direction and zero candidates.
Do not add formulas, labels or candidates solely to complete a template.
