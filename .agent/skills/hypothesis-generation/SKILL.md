# Hypothesis Generation

## Purpose

Formalize one selected candidate without reopening a broad idea search.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the selected candidate, current
claim, supporting observations and when the hypothesis arose.

## Workflow

1. Preserve H0-H3 provenance and identify the unresolved uncertainty.
2. State the favored mechanism and strongest competing explanation.
3. Derive divergent observations and the principal confound.
4. Specify the smallest confound-controlled comparison, unit, metric and rejection
   condition. State how positive, null, contradictory and boundary outcomes change
   the claim.
5. Name independent confirmation when an exploratory/post-hoc central claim needs
   it. Do not approve the direction, implement code or execute the experiment.

## Output

A falsifiable hypothesis pair, provenance, prediction, decisive test and outcome
interpretations. No hypothesis-count quota or plausibility score.

## Validation

Check that at least one possible result changes the scientific decision, the test
actually distinguishes the explanations and exploratory origin remains visible.
