# 11 Reference Check

## Purpose

Verify and correct the support for specified citations or changed claims.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the exact statement, bibliography
entry and relevant original source or official bibliographic record.

## Workflow

1. Identify which metadata or scientific support requires verification.
2. Inspect the original passage and official record. An abstract or metadata
   lookup alone does not establish full-text methods or absence of prior work.
3. Correct the entry or nearby claim when authorized. Preserve valid sources that
   legitimately lack DOI, volume or page range.
4. Report unresolved access or support issues that materially affect the paper.

## Output

Corrected wording and references, with any important unverified item clearly named.

## Validation

Recheck changed metadata and the original passage supporting each material claim.
Do not turn ordinary wording edits into full bibliography audits or generate
source archives, scores or receipts.
