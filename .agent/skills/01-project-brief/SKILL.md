# 01 Project Brief

## Purpose

Establish the research state needed to choose the next action, not a completed
metadata form.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the local state authority, user facts,
actual results and relevant prior decisions. Missing evidence stays unknown.

## Workflow

1. Identify object, environment, observation, task, observed failure or unresolved
   contradiction and desired understanding.
2. Record current claim, strongest evidence, competing explanation, largest
   uncertainty, next discriminating action and stopping condition.
3. Resolve only contradictions affecting the method, interpretation or scope.
4. Update `paper/core/02_RESEARCH.md` or the explicitly established local authority.
   Intake is optional one-time input, not a synchronized copy. Record approval
   only when the author actually made the relevant decision.
5. For a requested progress update or continuing staged research, refresh the
   existing `paper/core/07_PROGRESS.md` from that authority and inspected artifacts using
   the [status guidance](../../references/research_first_paper_loop.md#status-without-duplicate-authority).
   Keep it a readable progress view; do not copy approval fields or replace a
   requested experiment, implementation or manuscript change with this summary.

## Output

A usable current state and one next substantive action. Do not create another
status system, fill unknowns or require venue and author metadata before research.

## Validation

Reread the changed state against the inspected evidence and author decisions.
Check that no provisional idea became an approved direction and no local fact was
replaced with a template default.
For a progress view, check that its dated observations point to actual sources and
that missing results, failed execution and scientific contradiction stay distinct.
