# 08 Markdown Draft

## Purpose

Produce the requested manuscript section, preserving its valid scientific core.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the active source and adjacent text,
local scientific constraints, original sources, actual method and available
results. A draft claim is not evidence for itself.

## Workflow

1. Distinguish scientific revision, language revision and explicitly requested
   compression. Identify claims, definitions, assumptions, mechanisms, examples,
   equations, numbers, citations and boundaries that must remain.
2. Repair the actual argument before wording. Inspect relevant original sources
   or results when a change depends on them; do not fill gaps with invented prose.
3. Explain scientific meaning before implementation. A wrapper or task log does
   not establish a new formulation. Preserve legitimate technical objects and
   methodologically necessary details rather than mechanically deleting terms.
4. Draft the section with distinct strengths for fact, inference and hypothesis.
   Use only the relevant section-specific guidance in the existing research loop.
5. Keep the general method separate from default implementation and experimental
   configuration. Move necessary operational details to their appropriate location.

## Output

Revised manuscript text. For scientific revision/compression, briefly disclose
substantive additions, removals, movements or weakened claims. Pure polish must
preserve meaning and needs no whole-paper status report.

## Validation

Make one final claim-evidence, scientific-abstraction and reviewer QA pass against
the original and adjacent text. Correct actual defects minimally. Check changed
numbers, equations, citations and scope; do not run a prose scanner or another
reviewer loop.
