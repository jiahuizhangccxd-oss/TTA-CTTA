# Skill Directory Contract

Root `../../AGENTS.md` owns execution. [Paper Skill Core](../PAPER_SKILL_CORE.md)
owns common scientific and publication rules. `ROUTING_MATRIX.md` owns route
selection; individual Skills own only their local behavior.

Core Skills use Purpose, Required Evidence, Workflow, Output and Validation.
Retain extra sections only for distinct operational behavior or required licensing.
Paper, experimental-design and reviewer Skills explicitly link Paper Skill Core.
Do not duplicate its rules or repository-local scientific facts in every Skill.

An instruction must change inspection, action, output or validation. Supporting
libraries are not primary routes, and structural checks do not establish actual
Host behavior. Preserve the two existing host entries and on-demand loading.
