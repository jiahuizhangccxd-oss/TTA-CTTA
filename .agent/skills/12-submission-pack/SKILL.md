# 12 Submission Package

## Purpose

Prepare the actual uploadable package; preparation does not authorize submission.

## Required Evidence

[Paper Skill Core](../../PAPER_SKILL_CORE.md), the authoritative manuscript/assets,
current official venue requirements and genuine author/declaration information.

## Workflow

1. Verify the applicable article type and required files.
2. Build only the required manuscript, source, supplement, figures, bibliography,
   cover letter and declarations. Do not invent missing author, funding, ethics
   or conflict information.
3. Inspect files and correct actual inconsistencies. In a readiness-only request,
   remain read-only unless correction is authorized.
4. Leave external submission/publication to an explicitly authorized action.

## Output

The required files and a concise description of missing author inputs. A checklist
or readiness score is not a completed package.

## Validation

Open the files, verify inclusion and venue requirements, and compile changed TeX.
Confirm every claimed correction exists. Do not generate an audit package or
repeat full validation without an intervening change.
