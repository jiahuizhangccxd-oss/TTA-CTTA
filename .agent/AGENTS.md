# Internal Agent Scope

`../AGENTS.md` owns execution and repository operations.

| Concern | Authority |
|---|---|
| shared scientific and publication rules | `PAPER_SKILL_CORE.md` |
| detailed scientific reasoning and examples | `references/research_first_paper_loop.md` |
| intent to primary mapping | `skills/ROUTING_MATRIX.md` |
| minimum task context | `context_cards.md` |
| Skill inventory | `skills/INDEX.md` |
| current research state | `../paper/core/02_RESEARCH.md` |
| one-time intake | `../paper/kickstart/new_project_intake.yaml` |
| decision history | the two existing files in `../paper/logs/` |

`00-router` and explicit read-only `grill-me` are the only host entries. All other
Skills and optional ARIS capabilities remain internal. Local ownership documents
are navigation, not additional copies of execution or scientific policy.
