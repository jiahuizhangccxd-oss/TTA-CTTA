# 05｜综述问题、语料范围与综合协议

> 未绑定真实综述。作者直接编辑；AI 先提 diff，再经确认写入。
> 与论文类型无关的部分写“不适用及理由”；不把下列项目全部变成执行前置门槛。

## 1. 定位与真正的 Review Gap

| 决定 | 要明确的内容 | 本项目内容 |
|---|---|---|
| Review type | technical/narrative、systematic、scoping 或其他明确类型 | unknown |
| Research questions | 读者最终需要回答的科学/工程问题；引用 02 | unknown |
| Closest surveys | 最近邻综述、原文位置、已覆盖的分类/问题/时间范围 | unknown |
| Review Gap | 尚缺的是解释、比较条件或综合结论，不只是更新年份/更多文献 | unknown |
| Synthesis contribution | 去掉“整理/分类”动词后还剩什么新认识，如何由原文支持 | unknown |
| Scope exclusions | 不研究的对象、任务、方法、语言、文献类型及理由 | unknown |
| Author decision | 采用类型与范围的实际确认依据 | 尚未确认 |

研究问题、贡献强度和最大不确定性的权威是 [02_RESEARCH.md](02_RESEARCH.md)；此处只定义如何取得与综合语料。
已有综述可能否定候选 novelty；不能弱化其范围来制造 gap。

## 2. 检索与全文取得

| 项目 | 需写明的规则 | 本项目内容 |
|---|---|---|
| 检索源 | 实际能访问的数据库、原始出版页、预印本来源 | unknown |
| 检索式 | 关键词、同义词、布尔组合、领域邻近术语 | unknown |
| 时间 | 覆盖区间、实际检索日期、更新截止点 | unknown |
| 补充方式 | 向前/向后引用追踪、关键作者或基准；是否属于正式检索 | unknown |
| 纳入 | 对象、任务、方法、资料类型、全文条件 | unknown |
| 排除 | 具体可复核理由；不能因结论不利而排除 | unknown |
| 去重 | DOI/题名/作者核验；预印本与发表版视作同一工作但保存版本关系 | unknown |
| 全文路径 | 本地/共享文献库实际位置；尚未创建的文件夹不得称已归档 | unknown |
| 获取限制 | 合法可用版本、授权访问、无法取得的具体原文 | unknown |
| 数量与停止 | 作者实际要求；没有要求时不默认 50 篇或固定数据库配额 | unknown |

原文、BibTeX 和摘要是不同产物。若要求取得 PDF，逐项核对可打开、题名/作者/版本相符；
HTML 原文可用于核验但不是“已下载 PDF”。单篇不可访问只暂停该篇，不停止其他可取得文献；不绕过访问控制。
公开书目信息、已取得全文、深读并核验的独立工作分别统计，不混计。

正式 systematic/scoping 项目需要可追溯筛选流程与排除理由；按所选择方法保存在既有语料记录中。
普通技术综述也需交代检索边界，但不默认制造 PRISMA 流程图、双人筛选或 meta-analysis。

## 3. Taxonomy 与提取规则

| 内容 | 最小充分定义 | 本项目内容 |
|---|---|---|
| 分类对象 | 整篇工作、单个方法、模型组件还是实验设定 | unknown |
| 主分类轴 | 来自科学问题的机制/假设/信息访问差异 | unknown |
| 维度定义 | 各类别的可观察判据、边界和允许重叠 | unknown |
| 歧义处理 | 保留 uncertain/partial/not reported，何时回查原文 | unknown |
| 试读校准 | 选择覆盖不同机制的原文验证分类可用性；不是任选成功案例 | unknown |
| 比较轴 | 问题、假设、训练/部署信息、数据、评价、机制和边界 | unknown |
| 提取单位 | 正文段落/公式/表/图/补充材料的定位 | unknown |
| 质量与局限 | 与问题相关的方法缺陷、统计与外推范围 | unknown |

文献条目写在 [06_LITERATURE.md](06_LITERATURE.md)，分类依据需能回到原文。
“不报告”不等于“没有”；不强迫每篇论文落入唯一类别，不让 Ours 在每个维度天然占优。
若不同 setting、数据单位或指标不可比，保留差异，不对摘要中的准确率直接排名或平均。

## 4. 从原文到综合结论

每个重要综合论断说明：**问题 → 哪些原作共同支持/冲突 → 比较条件 → 更简单的竞争解释 → 本综述得到的新认识 → 适用边界**。
原作结论、作者推断、研究建议分开写。未取得关键全文时限制该项断言，不用模型记忆补齐。

| 待综合的问题 | 已核验原文与位置 | 一致/冲突/不可比 | 能支持的结论 | 仍缺什么 |
|---|---|---|---|---|

空表无需填满。形成真实结论后修改唯一正文；不要仅增加 taxonomy 表或进展条目。
对于理论、机制图和原图借用，分别核验科学关系、可编辑图源、来源标注和许可要求。

## 5. 什么时候停止

当前问题已由足够原文回答且新增检索不再改变分类或综合判断时，停止本次有界检索并写作；
这不是在未执行规定系统检索前擅自宣称覆盖完毕。达到作者预算或遇到关键访问缺口时，报告精确范围和剩余影响。
新原文否定 taxonomy 或 gap 时修订受影响的定义，不通过扩大题目或加入更多章节回避。

## 方法来源

[PRISMA 2020](https://www.prisma-statement.org/prisma-2020) 面向系统综述的透明报告；
[PRISMA-ScR](https://www.prisma-statement.org/scoping) 对应 scoping review。
二者按实际方法选用，不是所有技术综述的强制研究流程，也不能替代原文质量判断。
