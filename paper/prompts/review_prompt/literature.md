# 通用文献 Prompt 与综述论文入口

通用任务用于一次有明确问题的文献工作；六阶段入口用于写作综述论文（review/survey）。按当前缺口选用，不必依次完成，也不将写作综述与同行评审混为一项任务。

## 使用与边界

- 先读取目标项目的规则、已有材料和 [Paper Skill Core](../../../.agent/PAPER_SKILL_CORE.md)。沿用已有作者决定、文献记录、正文与状态权威；PaperTrace 项目沿用其 `active_source`，独立复制使用不要求建立 `paper/` 或另一套台账。
- 默认面向 technical/narrative survey；已有明确的 systematic/scoping review 方法时遵循实际协议。综述类型由研究目的与实际方法决定，不能仅因使用本文件或填写 checklist 就声称完成系统综述。
- 每个代码块是一项可独立复制的任务，一个主 Skill，至多一个确有必要的支持。Skill 链接用于定位能力；在外部项目先确认其是否实际可读、可用，不要求安装全套框架，也不声称使用了未读取或未运行的能力。
- 复用合格的已有材料；检索来源、篇数、分类维度、筛选人数与记录详度由本轮问题和综述方法决定。不默认要求 50 篇、两个数据集、物理 PoC、双人筛选或预注册。
- 只读审查、规划、正文修订与实际执行分别遵守本轮范围。缺少原文、检索渠道或运行能力时完成可行部分，保留具体缺口；计划、下载、阅读和科学支持是不同状态。

## 通用文献任务

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
主题与本轮问题：[需要文献回答的具体问题]
范围、目标读者与交付物：[研究边界、时间范围、目标段落/比较/综合]
已有材料与约束：[文献、正文、已采用的综述方法、可用渠道及资源]

围绕本轮问题完成所需文献检索、原文核验、比较与综合。
先读项目规则与适用的 Paper Skill Core，沿用有效材料、作者决定和唯一正文；
没有 PaperTrace 目录时使用现有载体，不为本任务初始化框架或另建状态权威。
复用已有原文，按缺口补充基础、近期、最相关及相反证据，并检查同义术语。
综述用于定位问题与追溯来源，关键方法、结果和能力边界回到原始研究核查。

核对论文身份、版本与出版状态；合并同一工作的预印本/正式版本，保留必要差异。
关联同一研究的多份报告，避免重复计权；题录、核验全文、实际深读与正式纳入分开。
按问题提取对象、假设、方法、条件、发现与局限，给出原文页码/小节/图表定位。
无法访问、未报告和明确不存在分别处理；来源身份正确不等于结论可靠。

按共同科学维度综合共识、分歧、不可比较条件和证据缺口，不逐篇堆砌摘要。
检查相反证据、研究局限及样本/数据重叠，区分原作发现、作者综合与待验证判断。
不同任务、数据集、指标或协议的性能不直接平均、排名或按显著结果投票。
不以篇数、引文量或期刊声望确认科学空白；未检索到不等于不存在。
检索与筛选记录按实际综述方法保留，不补造检索式、数量、排除理由或预注册。

交付本轮所需的可回查综合、比较或正文修改，并说明覆盖边界和影响结论的未知项。
只读任务仅报告发现。需要其他阶段时只推荐一个具体入口，给出最小材料后停止，
由用户启动下一任务；没有新增区分信息或已达资源边界时说明原因，不重复循环。
```

## 方法参考

以下规范用于适用类型的报告，不替代综述方法设计，也不证明已执行或证据质量：

- [PRISMA 2020 原文](https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.1003583)：系统综述的报告规范，有无 meta-analysis 均可能适用；如实报告实际方法、参与者和记录，不由此增加统一注册、双人或篇数门槛。
- [PRISMA-ScR 官方说明](https://www.prisma-statement.org/scoping)：范围综述的报告扩展；批判性评价按实际是否开展报告。
- [SWiM 原文](https://www.bmj.com/content/368/bmj.l6890)：用于系统综述中未进行效应量 meta-analysis 的定量干预效果综合报告，普通技术综述不因没有 meta-analysis 就自动适用。

既有 `literature-review` 的参考和模板按需取用；其中的数据库数量、临床量表或示例路径不作为本套 Prompt 的默认要求。定量汇总另用 [05：定量综合](05_synthesis_and_claims.md#定量综合)，先核实可合并性。

## 条件交接入口

多条条件同时成立时，只推荐一个最能改变当前判断的目标，给出依据与最小材料后结束本轮，由用户启动。可在本轮范围内解决的局部问题直接处理；必要输入缺失、预算耗尽或没有新增信息时说明原因并停止。

| 当前任务与触发条件 | 下一任务入口 | 最小交接材料 | 继续或返回标准 |
|---|---|---|---|
| 问题、读者或纳入边界不明确，无法判断相关性 | [01：综述问题与范围](01_review_question.md#综述问题与范围) | 当前主题、用途、已有材料与具体歧义 | 明确可回答的问题与边界后返回；不默认扩大为全领域综述。 |
| 关键既有综述、同义工作或原始依据尚未核实 | [02：围绕当前问题定向定位](02_literature.md#围绕当前问题定向定位) | 待判区别、已知来源与缺失依据 | 核实重叠和条件后修订具体判断，检索不足保持未知。 |
| 题录已知，决定性判断依赖尚不可核验的全文 | [02：获取并核验全文](02_literature.md#获取并核验全文) | 目标题录、版本线索和依赖原文的判断 | 获得对应原文或明确访问缺口；不重取已有合格材料。 |
| 文献可得，但分类或提取规则持续产生歧义 | [03：分类框架与提取规则](03_taxonomy_and_pilot.md#分类框架与提取规则) | 争议文献、现有维度、原文实例 | 定义与实例一致并经局部试运行后继续，不强行归类。 |
| 要开展正式纳入与综合，但检索、纳排或综合方法未明确 | [04：综述协议](04_review_protocol.md#综述协议) | 当前问题、探索记录、现有规则与资源 | 明确相称的方法后开展；保留方法形成的真实时间。 |
| 材料已有，中心结论的证据强度或适用范围未定 | [05：综述主张判断](05_synthesis_and_claims.md#综述主张判断) | 具体结论、支撑与相反原文、已知局限 | 明确保留、收窄、撤回或未定的论点后修订对应产物。 |
| 当前证据综合已足以支持目标章节 | [06：综述全文与论证](06_manuscript_and_submission.md#综述全文与论证) | 核验来源、综合结果、有效正文与边界 | 直接推进唯一正文，不为写作重复完整检索流程。 |
