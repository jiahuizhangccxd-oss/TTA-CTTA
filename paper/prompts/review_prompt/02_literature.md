# 综述文献：定位、探索、全文与比较

先读 [使用与边界](literature.md#使用与边界)，按本轮缺口选择一个任务。探索文献用于澄清问题与设计综述，不自动成为正式纳入集；正式检索、筛选和提取沿用实际综述协议。复用已有合格材料，不设通用篇数、矩阵行列或检索轮数门槛。

## 围绕当前问题定向定位

主 Skill：[03-literature-deep-research](../../../.agent/skills/03-literature-deep-research/SKILL.md)。

```text
先读取可访问的项目 README/AGENTS、Paper Skill Core、本轮原文与已有作者决定。
沿用项目现有文献、唯一正文和事实权威，不强制初始化 PaperTrace；
材料不可访问时说明缺口，显式只读与本轮授权继续有效。

围绕当前综述的一项定位疑问，核实会改变问题、范围或增量判断的原文。
先写明待判问题、已知材料，以及肯定、否定或仍未知时会怎样改变判断。
优先定位相同或等价问题的已有综述、原始研究和相反证据；
核查概念的等价术语、早期版本、相关范围和已经完成的综合，不能只查同名标题。
实际检索只使用当前可用且已授权的渠道，未访问的数据库不能报告为已检索。

数量和范围以解决本轮问题为准，不重做完整领域调研或全部比较表。
每项关键判断给出工作身份、版本、实际阅读状态、原文位置及其支持的内容。
同一工作的预印本与出版稿维护版本关系，不重复计作独立工作。
只读摘要或片段时不能推断某项机制、范围或分析在全文中不存在。
期刊档次、引用数、题名相似和措辞差异均不能代替实质重叠判断。

返回待判问题、最相关原文证据、重叠与差异、成立条件及对当前定位的影响。
区分已被覆盖、仅部分覆盖、存在实质差异与信息不足，不因未找到就宣布空白。
缺关键全文时列出精确条目和待核查内容，不以另一篇综述的转述补造原文结论。
沿用现有题录、原文与问题载体；探索所得条目不能未经正式筛选就计入纳入集。

已回答问题、达到约定预算、来源不可得或没有新增区分信息时结束。
只交接一项必要后续任务，不自动修订选题、下载全文或扩大检索。
```

## 探索检索与原文提取

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
先读取可访问的项目 README/AGENTS、Paper Skill Core、本轮原文与已有作者决定。
沿用项目现有文献、唯一正文和事实权威，不强制初始化 PaperTrace；
材料不可访问时说明缺口，显式只读与本轮授权继续有效。

围绕当前核心问题探索领域结构，补足设计综述所需的概念与原文材料。
本轮交付探索集及实际原文提取，不宣称已完成正式纳入、全面覆盖或系统综述。
已有正式协议时尊重其边界；改变检索或纳排规则的需求单独指出，不悄然改协议。

从核心概念、同义词、缩写与等价任务组织检索，选择与问题相符的可用来源。
结合基础研究、近期进展、既有综述、不同方法族、边界案例和相反结果，
按需要追溯引用与后续研究；不按声望优先排除相关证据，不为凑篇数补入弱相关工作。
记录实际检索渠道、日期、检索式或问题、时间与来源边界、访问限制及已有收录情况。
结果处理脚本只能整理已有检索记录，不能据脚本运行声称访问了数据库。

核验题名、作者、年份、出版状态、标识符及版本关系，保留既有编号和合格副本。
区分工作、论文版本和同一研究的多份报告，避免重复证据被当作独立支持。
按本轮问题实际阅读原文，提取研究问题、关键定义、假设、方法、
数据与评价条件、原文发现、限制及其与综述问题的关系。
保留 PDF 页码、章节、公式或图表等定位；没有报告的字段标为未报告或待核实。
综述可用于理解领域和寻找来源，涉及具体方法、效果或能力的论断仍回原始研究。

按可比较的科学维度整理初步共识、分歧、不可比较条件和提取困难，
说明探索集可能遗漏什么，不能以这批材料的分布代表整个领域。
区分原文报告与本综述的解释，既有综述本身作为比较对象时保持相应证据层次。

交付：可复用的探索题录、实际阅读与提取结果、原文定位、缺失来源和待判问题。
分别报告核验题录、身份正确全文与实际深读的状态；未知数量写未统计。
只更新项目现有文献载体，不建立平行文献库、筛选控制器或强制登记系统。
本轮结束后交接；需要正式检索、筛选和提取时转交相应协议与执行任务。
```

## 获取并核验全文

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。只有确有批量归档需要且实际可用时，以 `project-paper-curator` 作为本轮唯一支持。

```text
先读取可访问的项目 README/AGENTS、Paper Skill Core、本轮原文与已有作者决定。
沿用项目现有文献、唯一正文和事实权威，不强制初始化 PaperTrace；
材料不可访问时说明缺口，显式只读与本轮授权继续有效。

获取并核验当前指定批次的目标全文，先检查已有题录、文件、版本关系和归档记录。
批次可以是一项关键来源或本轮明确指定的清单；不把全部文献取得作为局部判断前提。
复用身份正确的合格文件、已有编号和有效负面核验结果。

按实际可用且已经授权的渠道获取出版稿、作者公开稿或预印本，记录版本与来源。
确需批量归档支持时，先定位并完整读取当前环境已有的 project-paper-curator：
https://github.com/LQQL1997/LQQL_OS/blob/6ad5308eee13fcc29be4e02a6bba3fb11a89a012/.agents/skills/project-paper-curator/SKILL.md
该链接只标识 canonical 来源，不能证明本地已经安装或可运行。
实际采用时仅使用它所需的获取、身份核查与归档能力，不再叠加第二项支持。
其本地 verify/archive 脚本不代替实际检索、来源访问或全文下载。
不可用时说明缺口，继续用现有且已授权渠道完成可行部分，不假装运行该 Skill。

核对首页题名、作者、标识符与版本关系；复杂首页按需实际渲染核查。
HTTP 200、扩展名、解析成功或参考文献中出现目标题名均不能证明文件身份正确。
HTML 原文可作为实际阅读载体，但不能称为已下载 PDF；无关文献不能补齐目标数量。
保留合法缺少 DOI 的来源，不因缺少某个标识符就判其为虚假。

分别报告：已核验独立工作、身份正确全文、实际深读、项目副本与缺失/待复核状态；
没有统计的量写未统计，不把下载、读过全文和已经正式纳入混为一项完成状态。
不可得的全文仍保留题录、权威补全入口、原因及受影响判断，不改写成正式筛选结论。
沿用已有归档记录；使用 curator 时不再建立另一套下载器或文献台账。
交付实际取得并核验的材料和剩余缺口后停止，由用户启动原文提取或其他后续任务。
```

## 科学比较矩阵

主 Skill：[03-literature-deep-research](../../../.agent/skills/03-literature-deep-research/SKILL.md)。

```text
先读取可访问的项目 README/AGENTS、Paper Skill Core、本轮原文与已有作者决定。
沿用项目现有文献、唯一正文和事实权威，不强制初始化 PaperTrace；
材料不可访问时说明缺口，显式只读与本轮授权继续有效。

针对当前问题，以实际读过的原文构建或局部修订科学比较矩阵。
先明确本轮比较对象：综述定位比较既有综述的问题、范围、组织原则、证据与综合深度；
原始研究比较科学问题、假设、机制、数据/评价条件、发现与边界。
两类对象可以分别比较，不能把综述是否覆盖某主题混成方法是否具备某能力。

从待回答问题和原文导出有区分力的维度，数量与所需证据相称，不设固定行列门槛。
局部核查只处理受影响的格子；已有矩阵保留有效内容、来源身份和比较条件。
保留已有工作的真实优势，不以组件数量或让本综述多打勾为目标。
把本综述列入定位表时，明确哪些已经完成、哪些仍是拟议内容，不能提前判为已覆盖。

每项重要判断指向 PDF/原文位置、页码、章节、公式或图表及支撑内容。
区分充分处理、部分处理及其条件、有明确原文依据的缺席、信息不足。
未报告不等于不存在，摘要未提及不能支撑全文级缺席判断；
有争议或不可二值化的内容用具体文字，不用符号代替科学差异。
不同信息权限、研究对象、指标或协议下的数值不能直接排名或推出普遍优劣。

交付本轮实际需要的比较表、维度依据、关键格子来源和具体定位结论。
分清原文已经解决的问题、本综述拟做的综合以及已有证据支持的新认识。
没有必要时不另制完整英文表、LaTeX 或整节正文；确需投稿表时适配现有格式。
有授权时只更新既有矩阵、相关唯一正文与题录，只读任务直接返回结果。
保留关键原文缺口；探索比较不能冒充正式纳入文献的完整综合，交接后结束本轮。
```

## 条件交接入口

只选择一项最有信息量的目标，给出触发依据、最小材料和返回标准后停止；后续任务由用户另行启动。没有实质缺口时完成当前任务，不重检已有效的来源。关键来源不可得、预算耗尽或没有新增区分信息时说明原因，不反复推荐同一检索。

| 当前任务与触发条件 | 下一任务入口 | 最小交接材料 | 继续或返回标准 |
|---|---|---|---|
| 定向定位或探索检索：对象、概念或范围无法限定待判问题 | [01：综述问题与范围](01_review_question.md#综述问题与范围) | 已有材料、检索困难及不清楚的边界 | 明确核心问题与本轮边界后返回，不能通过无限扩词代替问题澄清 |
| 任一文献任务：目标已定位，关键判断仍缺身份正确的可读全文 | [获取并核验全文](02_literature.md#获取并核验全文) | 精确题录、版本线索、已有副本及待核查内容 | 核验全文后返回原判断；无法取得时保留具体缺口，不把未读判为不存在 |
| 全文核验：当前用途为探索，来源已具备但尚未提取其科学内容 | [探索检索与原文提取](02_literature.md#探索检索与原文提取) | 实际全文、版本、待提取问题及已有提取结果 | 完成当前所需提取并保留原文位置，不冒充正式纳入文献的全量提取 |
| 定向定位或提取：相关原文已读，需要逐维比较以核实重叠与差异 | [科学比较矩阵](02_literature.md#科学比较矩阵) | 原文位置、待判维度、现有表格及争议断言 | 形成可回查的局部或完整比较，不以表格符号直接宣布综述增量成立 |
| 定位或比较：已有综述覆盖拟议增量，或新证据改变当前选题判断 | [01：综述增量与选题判断](01_review_question.md#综述增量与选题判断) | 原判断、覆盖/矛盾原文及仍有效的问题 | 保留、收窄、修订或撤回受影响增量，不只改名或扩充篇数 |
| 探索检索或比较：问题与方向明确，但分类维度或提取字段尚不能组织证据 | [03：分类框架与提取规则](03_taxonomy_and_pilot.md#分类框架与提取规则) | 核心问题、异质原文、初步维度及提取困难 | 形成可操作的分类与提取规则，避免按论文顺序逐篇罗列 |
| 探索提取：已有分类规则，但边界案例持续产生归类歧义 | [03：小样本试运行](03_taxonomy_and_pilot.md#小样本试运行) | 现用规则、实际案例、原文位置和歧义记录 | 用代表及边界案例校准规则；小样本表现不证明整个领域已被覆盖 |
| 探索任务：需要建立正式纳入集，但检索、纳排或综合协议尚不明确 | [04：综述协议](04_review_protocol.md#综述协议) | 核心问题、探索来源、访问限制及待定规则 | 明确适合综述类型的协议后再执行正式收集，不把探索集直接改称纳入集 |
| 文献准备：正式协议已明确，下一任务是全量检索、筛选与提取 | [05：执行检索筛选与提取](05_synthesis_and_claims.md#执行检索筛选与提取) | 现用协议、已有合格记录、全文、截止日期与资源范围 | 按实际协议核验纳入及排除，复用材料但保留不同完成状态 |
| 比较矩阵：关键来源身份、等价概念或局部缺席判断仍无法核实 | [围绕当前问题定向定位](02_literature.md#围绕当前问题定向定位) | 出错条目/格子、原文疑点和待判问题 | 只核查受影响范围并返回，不重建文献库或重跑全部调研 |
