# 分类框架与小样本试运行

遵循 [使用与边界](literature.md#使用与边界)。本阶段检验分类和提取规则能否回答综述问题；小样本试运行提供方法修订依据，不代表全领域覆盖，也不要求物理仿真或模型实验。

## 分类框架与提取规则

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
围绕当前综述问题、已核验原文和已有分类，形成最小必要的 taxonomy 与提取规则。
先读项目规则、Paper Skill Core、作者决定及现有载体，保留有效维度与术语。
独立复制使用时沿用本项目的正文与记录，不要求建立 PaperTrace 文件结构。

从研究对象、问题假设、信息条件、方法原理、评价设置或结果边界中选择
能解释文献差异的维度；逐项说明它回答的问题及与既有综述分类的实质关系。
不能只按模型名称、年份或工具目录分组后宣布形成新框架。
为每个维度给出定义、粒度、归类依据、典型实例与易混淆边界，保留原文定位。
区分来自已有工作的类别与本文提出的组织方式，不把作者解释写成原作自述。

区分维度之间与维度内部的关系；允许有依据的多标签、层级或连续属性。
互斥与完备只在该维度确实需要时论证，不为得到整齐表格强迫所有工作单归类。
未报告、不可判断、不适用与明确缺少分别记录，不能把空白变成“无此能力”。
按问题确定提取字段与统计单位，关联同一研究的多份报告，避免重复计权；
保留必要的任务、数据、指标、比较条件、结果、局限和来源定位，不机械填全字段。

用现有异质实例说明规则是否可操作，列出需要试筛选、试提取或试编码的歧义。
交付可使用的分类定义、提取规则与实例，更新既有载体而非新建平行台账。
尚未试用的框架标为暂定，不声称已验证优越或穷尽领域。
需要原文或试运行时推荐一个具体任务后停止，由用户启动。
```

## 小样本试运行

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
用实际可读的少量异质文献，试运行当前筛选、提取与分类规则。
先读综述问题、现有规则、已核验全文和实际方法说明，保留已有作者决定。
选择能暴露不同方法族、模糊边界、相反证据与信息不足情况的文献，
说明选择理由与试用范围；不设固定篇数，也不只选择容易归类的正例。

逐篇执行与本轮有关的纳排判断、原文提取及编码，给出决定和原文依据。
记录实际执行者、工具与不确定项；单人或同上下文的重复处理不能写为双人独立复核。
区分规则不清、原文未报告、全文缺失和执行错误，不用猜测补齐单元格。
比较类别粒度、字段可得性、重复维度与解释作用，允许合理多标签或保留未知。
试运行未覆盖的类别与条件保持未测试，不以样本归类成功宣称全领域适用。

根据实际问题提出或实施本轮已授权的最小规则修订，说明前后差异与影响。
规则变化影响先前编码时复核受影响记录，保留探索形成的时间和依据；
不为迎合预设结论删除反例，也不将结果后形成的规则写成预先协议。
交付实际试用记录、修订后的可操作规则、剩余歧义及是否足以开展正式综述的判断。
存在决定性缺口时只推荐一个下一任务并停止，没有新信息时不重复试用循环。
```

## 分类与解释的反例检查

主 Skill：[scientific-critical-thinking](../../../.agent/skills/scientific-critical-thinking/SKILL.md)。本项保持只读。

```text
只读检查本次指定分类规则或跨研究解释，先读定义、原文实例和实际试用记录。
沿用项目规则与 Paper Skill Core，区分来源发现、作者组织方式和进一步推断。
寻找会改变当前判断的最强边界案例、替代分类或竞争解释，不扩展为全稿审查。

核查维度是否循环定义、粒度混杂、重复表达或遗漏决定性条件，
是否将未报告判为不存在，是否把同一研究重复报告当成相互独立的证据。
解释文献差异时检查任务、数据、指标、信息权限与评价协议，
不能把这些条件差异直接解释为某个方法族的因果优势。
若主张框架解释力更强，核对实际比较依据；仅给出新名称或更细分类不足以成立。

每项发现给出规则或解释位置、原文反例、影响、最小修订与重新检查条件。
区分实际矛盾、缺少支持和目前不可评估；没有发现问题只说明已检查的范围。
本轮不改分类、记录或正文，不启动多轮 reviewer 循环或按分数批准框架。
需要修订时交接一项具体任务，由用户启动。
```

## 综述框架图

主 Skill：[15-figure-table-design](../../../.agent/skills/15-figure-table-design/SKILL.md)。

```text
依据实际综述问题、现用 taxonomy 与试用结果，制作或修改本轮指定的综述框架图。
先读项目规则、Paper Skill Core、分类定义、已有图源与目标读者需求。
图中每个类别、层级、映射或箭头都对应明确含义和来源；
概念关联、时间演进、包含关系与已验证因果关系使用不同且准确的表达。
不把检索工具、仓库目录或处理日志画成研究领域的科学机制。

选择能回答读者问题的必要层次，标明作者提出的组织框架及暂未解决的边界。
覆盖、分布和趋势图使用实际纳入及编码数据；暂定框架或试用样本不能充当全领域统计。
概念图与定量证据分开，不能用 AI 图像生成精确计数、数据曲线或已验证收益。
需要概念构图支持时至多选用一项实际可读、可用的支持，不强制调用外部服务。

沿用已有绘图后端和一个可维护图源，按本轮要求生成实际图件与自包含 caption。
可编辑对象应是独立文字、形状和连线，嵌入整张位图不算可编辑重构；
原生软件编辑验收只按实际打开、编辑、保存和重开结果报告。
打开产物检查科学关系、标签、图例、缩放可读性和证据边界。
仅规划时交付规格与缺失输入；缺工具时准确说明未生成部分，不把规格当作图件。
发现分类实质冲突时只交接相关任务，排版问题在本轮范围内解决。
```

## 条件交接入口

只推荐一个能解决当前主要缺口的目标，说明依据、最小材料与继续条件后结束本轮，由用户启动后续任务。保留有效原文、规则、图源、正文和作者决定；输入缺失、预算耗尽或没有新信息时停止，不反复交接同一事项。

| 当前任务与触发条件 | 下一任务入口 | 最小交接材料 | 继续或返回标准 |
|---|---|---|---|
| 分类、试运行或图示：综述问题或对象边界不清，分类目标无法确定 | [01：综述问题与范围](01_review_question.md#综述问题与范围) | 现用问题、争议对象与分类目的 | 明确范围后只修受影响维度，不重启无关选题。 |
| 分类、反例检查或框架图：已有综述可能使用等价框架，增量尚未核实 | [02：围绕当前问题定向定位](02_literature.md#围绕当前问题定向定位) | 当前框架、疑似等价来源与待判差异 | 核实分类依据与解释增量，允许复用、修订或撤回新颖性判断。 |
| 试运行或反例检查：争议判断依赖未获取的全文 | [02：获取并核验全文](02_literature.md#获取并核验全文) | 具体题录、版本线索、缺失段落和判断 | 核验后复查相关项，无法获取则保留不可判断。 |
| 分类规则已明确，但尚无实际试用，或重要修订影响先前编码 | [03：小样本试运行](03_taxonomy_and_pilot.md#小样本试运行) | 规则、受影响记录、异质实例及待判问题 | 检查实际提取与归类，发现的问题可改变规则；不以跑完样本证明覆盖。 |
| 分类或试用：关键分类原则或跨研究解释存在实质疑点 | [03：分类与解释的反例检查](03_taxonomy_and_pilot.md#分类与解释的反例检查) | 定义、原文依据、最可疑实例及当前解释 | 获得有定位的只读判断，不以未发现反例替代验证。 |
| 试运行、反例检查或图示：原文可得，问题来自定义、粒度或提取规则 | [03：分类框架与提取规则](03_taxonomy_and_pilot.md#分类框架与提取规则) | 歧义实例、原文、具体规则与影响 | 仅修订相关规则并复核受影响记录；不为消除反例强行归类。 |
| 试运行：问题来自检索覆盖、纳排原则或研究单位，而非分类定义 | [04：综述协议](04_review_protocol.md#综述协议) | 实际试用、失效规则、范围与资源 | 明确方法修订与已处理记录的影响后继续，保留真实变更时间。 |
| 分类和试用已足够清晰，尚缺正式检索与综合方法 | [04：综述协议](04_review_protocol.md#综述协议) | 可操作规则、实际试用、未知项与资源 | 制定与综述类型相称的方法，不将试用记录冒充正式完整纳入集。 |
| 框架与方法均已明确，需要执行余下文献处理 | [05：执行检索筛选与提取](05_synthesis_and_claims.md#执行检索筛选与提取) | 现用协议、规则、已有记录与实际来源 | 复用合格记录，实施余下任务并保留未知和排除依据。 |
| 反例检查或框架图：中心解释超出实际证据，需判断能否保留 | [05：综述主张判断](05_synthesis_and_claims.md#综述主张判断) | 具体结论、支撑原文、反例和局限 | 明确允许措辞后返回相关定义、正文或图件，不靠重命名维持强论断。 |
| 概念框架已一致，实际综合材料齐备，需要生成正文中的最终图件 | [06：综述图表定稿](06_manuscript_and_submission.md#综述图表定稿) | 现用分类、实际图源、综合数据与目标尺寸 | 检查最终图件和 caption；框架图本身不证明科学结论。 |
