# 证据执行、跨研究综合与综述主张

按 [使用与边界](literature.md#使用与边界) 继承有效材料、作者决定和项目状态权威。
默认服务 technical/narrative review；只有本项目实际采用 systematic/scoping
设计时，才执行相应协议并采用适用的报告要求。PRISMA 2020/ScR 是报告规范，
不能代替综述实施方法，也不据此增加固定篇数、数据库、双人、注册或数据集门槛。
沿用现有文献、提取、正文与进展载体，不为本阶段新建状态文件或平行台账。

## 执行检索筛选与提取

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
依据当前综述问题、范围和既有协议，执行本轮必要检索、筛选与原文提取。
先读本项目 README/AGENTS、Paper Skill Core、已确认规则及现有文献材料；
复用有效检索与提取结果，不因进入本步重新收集所有文献。

需要专项支持时，仅选择 K-Dense literature-review，并读取固定版本入口：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/literature-review/SKILL.md
采用本轮需要的检索、来源核验与提取能力；本项目综述类型和协议优先，
不照搬上游数据库组合、文献数量、筛选人次、注册或流程文档要求。

使用实际可用检索渠道，保留真实查询、检索日期、覆盖范围及选择理由。
按当前规则判断相关性并去重；同一研究的多篇报告建立关联，不重复计作独立研究。
systematic/scoping 设计按既定协议保留必要筛选与排除记录；
普通 technical/narrative review 说明实际覆盖与选择边界，不虚称穷尽检索。

对用于论证的原始来源提取问题、对象、假设、方法、数据与评价条件、
实际发现、负结果和局限，并给出可回查的原文位置及来源身份。
分别标明原文未报告、全文不可得、尚未核验和证据矛盾，不能相互替代；
摘要或二手综述可用于定位，不能代替关键结论的原文支持。

更新项目既有文献集合、提取记录和科学比较矩阵，核对关键条目与原文。
返回实际取得和核验的材料、覆盖边界及仍影响综合的具体缺口。
没有访问或执行能力时交付可行部分，不声称检索、下载或核验已经完成。
```

## 跨研究综合

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
基于当前综述问题、已核验原文和现有比较矩阵，形成跨研究的解释与综合。
先读本项目规则、Paper Skill Core、分类与提取规则及其适用边界；
沿用经试运行有效的框架，不把逐篇摘要拼接成综合结论。

需要专项支持时，仅选择 K-Dense literature-review，并读取固定版本入口：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/literature-review/SKILL.md
采用证据组织、跨研究比较与主题综合能力，不导入另一套综述流程或状态记录。

围绕共同科学维度比较研究问题、假设、机制、信息条件、评价协议和结果边界，
解释哪些发现一致、哪些冲突、哪些因条件不同而不可直接比较。
同名指标或同一数据集不保证比较公平；不同任务、划分、预算、基线、
样本与报告方式造成的差异必须保留，不能汇总排行榜来证明方法普遍优越。

区分三类陈述：原研究实际报告的发现；综述作者由多项证据形成的综合解释；
尚未验证的机制假设与研究议程。综合解释列明证据链、反证及适用条件，
研究建议说明待检验问题，不改写为领域已经建立的事实或共识。

同时检查研究设计、偏差、证据依赖、缺失报告和反例；不能用论文数量、
正负结果投票、引用量、发表场所或作者推荐代替效应与证据强度。
未检索到研究不等于不存在研究，缺少报告不等于方法没有该能力。

在既有综合记录或授权正文位置形成可追溯的主题论证，保留冲突与不可比条件。
输出已经支持的跨研究认识、尚不能排除的解释和影响结论的最小缺口；
没有实质缺口时完成本步，不为扩大覆盖或填满分类继续重启检索。
```

## 定量综合

主 Skill：[statistical-analysis](../../../.agent/skills/statistical-analysis/SKILL.md)。仅在问题适用且实际数据足够时使用。

```text
先读本项目规则、Paper Skill Core、实际提取数据与分析协议，判断定量综合
能回答什么问题。明确目标量、比较、指标和独立单位，再决定方法。
来源数量或表格完整不等于具备统计合并条件，不预设本综述必须做 meta-analysis。

需要专项支持时，仅选择 K-Dense statistical-analysis，并读取固定版本入口：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/statistical-analysis/SKILL.md
按本次设计采用必要估计、假设检查和不确定性分析，不机械使用显著性检验。

区分数量/比例等真实描述性统计、效应量合并和其他定量综合。
描述性统计说明统计对象、分母与覆盖边界，不为套用 meta-analysis 补造方差。
效应量合并核对效应定义、方向、单位、方差、样本量和缺失情况；方差可来自
原文或由可核验的原始统计量按适用公式推导，保留输入、转换依据与假设。
核对任务、干预/方法、对照、结局、时间点与评价协议是否支持同一估计目标，
不猜测缺失效应或样本量，不把不同指标直接平均。

识别重复报告、重叠样本、共享对照、配对/聚类和同一研究的多个结局或设置。
论文数、数据集数、fold 数、运行次数和随机种子数均不能自动视作独立样本数。
明确分析单位并处理依赖；无法厘清时说明对估计和不确定性的影响。

只有可比性、实际数据与依赖处理足以支持时，才执行相应定量分析。
选择与问题匹配的最简单方法，报告效应及适用不确定性、异质性与结论边界；
随机效应模型不能修复概念不可比。敏感性、偏差或其他检验按实际问题需要开展，
不在看到结果后换指标或模型，不把不显著解释为无效应。

不能做效应量 meta-analysis 时，仍可按问题与实际数据采用合法的其他定量综合，
如实命名方法与可回答的问题；不把所有非 meta-analysis 综合都叫作定性综合。
定量可比条件或必要信息不足的部分退回结构化定性综合，说明具体限制，
保留已有有效定量描述；不能用排名、显著性投票、无依据均值或虚构数据冒充 meta-analysis。
只有系统综述仍能合法综合定量干预效应、但至少部分结局不能或不宜进行效应量
meta-analysis 时，才按适用范围采用 SWiM 报告实际综合方法与结果；
它不规定如何开展综合，也不是质量评分工具。普通技术或叙述综述不能仅因
未做 meta-analysis 就默认套用 SWiM。

更新既有分析输出与相关图表数据，保留输入、计算入口及直接核验结果。
只有实际执行的计算才能报告新增统计结果；引用原研究数值时标明来源。
说明哪些结论仍需定性解释或不能成立。
```

## 综述主张判断

主 Skill：[05-claim-evidence](../../../.agent/skills/05-claim-evidence/SKILL.md)。

```text
基于当前综述问题、最近邻综述与原始研究、分类框架和实际综合结果，
判断本文新增了什么可支持的认识。先读项目规则、Paper Skill Core 和真实材料，
不能只依据另一 Agent 的成功总结或分类名称判断贡献。

需要专项支持时，仅选择 K-Dense scientific-critical-thinking，并读取固定版本入口：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/scientific-critical-thinking/SKILL.md
采用证据强度、隐含假设和竞争解释检查，不以模型评分或固定轮数评审代替判断。

区分原研究发现、综述作者的跨研究综合、尚未验证的解释与研究议程。
逐条核查分类、趋势、比较、机制、因果或研究缺口主张分别需要什么证据，
哪些材料实际支持；统一术语、较新文献或更大列表本身不自动构成科学增量。

检查最近邻已有综合是否覆盖相同问题，分类能否解释真实差异，
结论是否保留反证、负结果、局限、不可比条件和证据依赖。
描述性覆盖不能证明检索穷尽；方法出现频率、排行榜或研究数量投票
不能证明效果优劣、因果机制、普遍适用或领域共识。

对候选主张给出原始依据、最强替代解释、适用范围和允许写入正文的措辞。
按证据保留、收缩、否定或保持未决；如使用 Supported / Refuted / Inconclusive，
它们只是对当前主张的判断，不新增状态字段或强制写作门槛。
有效反证可以否定具体主张，缺原文、数据不完整或不可比通常意味着仍不能判断。
未检验的建议保持研究议程，不能作为已经验证的综述发现。

更新因本次判断而过时的既有综合与贡献表述，继承有效材料和作者方向决定。
返回仍成立的综述增量、不能下的结论和一个最有信息量的后续任务。
证据已经足够时完成判断；不能靠追加文献、换分类名称或删去反例挽救强主张。
```

## 条件交接入口

当前任务完成或发现需要其他任务处理的实质缺口时，按下表交接。多条同时成立时，
只推荐一个最有信息量的目标，说明触发依据、最小材料与继续条件，然后结束本轮。
交接不自动执行目标任务，由用户启动；未命中条件时继续当前任务。
继承有效原文、提取、综合、负结果、作者决定和项目既有状态权威，不新建状态文件。
无实质缺口不重启先前任务；缺必要输入或无法获得新增区分信息时，说明原因并停止。

| 执行或综合：问题、对象或覆盖边界不清，无法一致判断纳入与结论范围 | [01：综述问题与范围](01_review_question.md#综述问题与范围) | 冲突实例、既有范围、受影响来源与作者决定 | 澄清真正影响判断的边界后返回原任务，保留仍有效的材料，不重新填写全部输入。 |
