# 综述协议与证据图表蓝图

按 [使用与边界](literature.md#使用与边界) 选择当前任务。默认面向 technical/narrative survey；
systematic 或 scoping 路径按实际问题与方法采用。协议与蓝图是执行依据，不能冒充已完成的检索或综合。

## 综述协议

主 Skill：[literature-review](../../../.agent/skills/literature-review/SKILL.md)。

```text
依据当前综述问题、已核验的文献定位、分类框架与试运行结果，形成可执行的综述协议。
先读项目规则、Paper Skill Core、已有协议与作者决定，继承有效范围和来源记录。
本轮设计，不把检索计划、筛选流程或拟综合的模式写成已经发生的结果。

读取 K-Dense 的 literature-review，采用其检索边界、原文提取与综合设计能力：
https://github.com/K-Dense-AI/scientific-agent-skills/blob/a1043ef544e3a100c28e70a736b6cf32554d0677/skills/literature-review/SKILL.md
只采用服务本次综述的问题与方法，不机械复制上游领域模板或安装整套环境。

1. 明确本综述回答的问题、关键概念、对象与适用条件，以及相对已有综述的增量。
   默认采用与目标相称的 technical/narrative survey；若采用 systematic 或 scoping
   路径，说明其问题与实际方法为何适合该类型，不仅根据标题或表格数量命名。
2. 给出可操作的范围与选择规则：覆盖对象、时间、语言、出版状态、来源类型，
   以及为什么采用这些边界。区分检索记录、文章/报告、独立工作及同一工作的版本，
   不将同一研究的多个版本或报告重复计为独立证据。
3. 设计实际可用的检索：概念组、等价术语、邻近机制、相反证据、引用追踪与来源。
   根据问题、可访问渠道和覆盖缺口选择来源；不预设数据库名单、篇数或数据集门槛。
   写明需要保存的实际检索式、日期、限制、去重与纳排理由；普通 survey 如实报告
   其选择方式和覆盖限制，不通过补画流程图宣称穷尽检索。
4. 定义筛选与提取规则、必要原文字段、页码/章节等定位及缺失信息的处理。
   字段围绕科学问题、假设、机制、条件、证据、结果与局限，说明多标签或模糊边界。
   报告实际承担筛选、提取与复核的人或工具及其职责，不虚构双人独立复核。
5. 按主张选择必要的证据评价：关键假设是否成立、比较是否公平、结论是否超过
   数据/证明、哪些条件不可比，以及负结果、反例与报告缺失如何影响解释。
   原文未报告与已证明不成立分开；不以引用数、期刊档次或统一总分替代科学判断。
6. 明确综合方式：概念/机制分类、主题与争议综合、描述性统计，或条件满足时的
   定量综合。预先说明比较单位、分组依据、必要变量与解释边界；异质指标和协议
   不能直接拼成统一排名。定量综合的可行性由真实提取数据决定，不预设 meta-analysis。
7. 给出工作优先级、实际访问与资源限制、直接核验方式和停止条件。
   发现足以改变范围或综合的证据时明确修订及理由，不把后来的规则写成预先决定；
   缺少关键原文、达到资源边界或没有新增区分信息时说明具体缺口，不为凑数扩展。

systematic 路径按适用范围参考 PRISMA 2020，scoping 路径参考 PRISMA-ScR：
https://www.prisma-statement.org/prisma-2020
https://www.prisma-statement.org/scoping
二者是报告规范，不代替 conduct 方法或证明方法质量。报告实际执行的方法；
未注册或未准备预先协议时如实说明，不能补造注册、检索数或预先决定。
PRISMA-ScR 的批判性评价在与综述目标相关且确已实施时报告，不自动变成统一门槛。
不把医学问题框架、固定人数、注册或 meta-analysis 要求套给所有技术综述。

输出现有协议载体的必要更新、分类/提取规则引用、综合计划、覆盖限制与待解决输入。
区分原作发现、本文拟做的综合和未验证的研究议程；没有写权限时返回可直接使用的协议。
沿用已有文献、证据及状态权威，不为本任务另建平行计划、运行台账或 readiness 状态。
```

## 证据图表蓝图

主 Skill：[15-figure-table-design](../../../.agent/skills/15-figure-table-design/SKILL.md)。

```text
依据当前综述问题、已核验原文、分类与提取规则、现有证据及协议，设计证据图表蓝图。
本轮制作能指导提取和综合的模板，不把尚未完成的检索、编码或计算画成结果。
沿用已有图源、表格和编号，只保留承担独立论证职责的图表。

读取 nature-figure，采用面板证据分工、图例与科学表达指导：
https://github.com/Yuan1z0825/nature-skills/blob/f8797feed6405035e7d57f59cb8ba393c6a98802/skills/nature-figure/SKILL.md
仅采用本次规划相关资源；不启动定量绘图或生成伪造数据，不机械创建全部上游产物。

先给出“综述问题 → 待支持结论 → 所需来源/字段 → 图表”的对应关系。
根据实际论证选择分类框架、证据覆盖图、机制/假设比较、争议与失效边界等形式，
而不是每种图都创建一张。分类图说明类别依据、交叉关系与未知项，不强行互斥。

每张表给出可直接使用的行列、英文标题、字段定义、比较条件、原文定位和缺失标记。
每张图给出英文 caption、面板布局、轴/单位、分组、图例、所需数据及其解释边界。
若比较已有综述，围绕覆盖范围、组织原则和综合深度；不将方法论文的 Ours 排名表
搬进综述，也不以更多勾选项证明本综述的增量。

数量图必须定义计数单位与分母，明确多标签、同一工作多报告、缺失和重叠来源怎样处理。
性能或效应图明确数据/任务、协议、指标、独立单位、效应及不确定性所需字段；
不同评价条件下的原文数字不能直接汇成优劣排名。必要字段不足时保留 TBD 与补充需求。
systematic/scoping 路径的筛选流程图只能依据真实记录生成；本轮尚无记录时仅列字段。

原作的测量/证明、作者的跨研究解释与未来研究建议应能在图注和正文中区分。
共现、引用数量和可视化聚类不自动构成机制、因果或重要性证据；预期模式不是发现。
同时设计会改变结论的反例、负结果或条件不一致怎样呈现，避免只展示支持性证据。

交付现有载体中的完整模板、各图表需要的最少字段与来源、caption 和仍缺的输入。
本轮不批量生成结果图；最终图表由真实提取数据和实际综合驱动，不把蓝图称为已完成图件。
```

## 条件交接入口

依据实际缺口或已完成任务，只推荐一项最有信息量的下一步；给出最小交接材料后结束本轮，
后续由用户启动，不自动执行目标任务。没有实质缺口时不重启有效工作；保留来源、作者决定与状态权威。
缺少必要输入、达到资源边界或没有新增区分信息时说明停止原因，不反复推荐同一任务。

| 当前任务与触发条件 | 下一任务入口 | 最小交接材料 | 继续或返回标准 |
|---|---|---|---|
| 综述协议：核心问题、概念边界或覆盖对象尚未明确，无法形成选择与提取规则 | [01：综述问题与范围](01_review_question.md#综述问题与范围) | 当前问题、模糊边界、已有材料与受影响规则 | 明确范围及理由后只更新受影响协议，不重新发散无关主题 |
| 综述协议：已有综述的覆盖或组织方式尚未核实，影响本综述定位 | [02：围绕当前问题定向定位](02_literature.md#围绕当前问题定向定位) | 当前增量、已知近邻综述、待核实的重叠点与条件 | 核实具体来源后再判断差异；不把检索未命中写为已有工作缺失 |
| 综述协议：已核实的近邻表明拟议增量不足，需要重新判断综述价值 | [01：综述增量与选题判断](01_review_question.md#综述增量与选题判断) | 近邻原文、范围/组织/综合差异、仍可成立的增量 | 明确可辩护的贡献或收缩范围后返回；已有方向决定不被模型推荐覆盖 |

| 综述协议或证据图表蓝图：类别、字段或比较单位无法稳定操作，存在歧义或冲突 | [03：分类框架与提取规则](03_taxonomy_and_pilot.md#分类框架与提取规则) | 冲突来源、类别/字段定义、边界案例与受影响图表 | 规则可解释、未知与交叉情况有明确处理后返回，不以强行归类消除反例 |
| 综述协议：规则已明确，但尚未验证提取可行性或关键字段能否实际取得 | [03：小样本试运行](03_taxonomy_and_pilot.md#小样本试运行) | 现有规则、待验证环节、已定位原文与资源限制 | 形成真实试运行结果并修正必要规则后返回；已有有效试运行直接沿用 |
| 综述协议：问题、来源选择、提取规则和综合方式已明确，需要组织证据呈现 | [04：证据图表蓝图](04_review_protocol.md#证据图表蓝图) | 现用协议、问题/主张对应关系、已有字段与证据缺口 | 图表职责与真实字段对应，未取得数量保留 TBD，再交接执行任务 |
| 证据图表蓝图：拟支持的结论需要协议未定义的比较、分组或综合方法 | [04：综述协议](04_review_protocol.md#综述协议) | 受影响主张/图表、缺失字段或比较条件、当前规则 | 明确证据如何取得与综合后返回，不通过理想图样或更强 caption 补齐方法 |
| 综述协议与证据图表蓝图：必要规则、来源渠道和本轮范围齐备，需要实际完成检索、筛选与提取 | [05：执行检索筛选与提取](05_synthesis_and_claims.md#执行检索筛选与提取) | 协议、提取规则、现有来源记录、图表字段、资源与停止条件 | 执行任务依据真实来源与记录更新材料；协议和模板齐备不等于检索、提取或综合已经完成 |
