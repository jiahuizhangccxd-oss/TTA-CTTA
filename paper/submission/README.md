# 可选投稿模板

恢复 PR #19 删除的投稿材料。它们只是可复用起点，不是每个项目必须填写的文件，也不改变 `paper/core/02_RESEARCH.md` 的状态权威。

- `cover_letter.md`：投稿信。只有核实后才能使用原创性、未同时投稿和全体作者批准等确认语句。
- `author_info.md`：投稿时整理作者信息；以已确认作者资料为准，不新增一套批准状态。
- `declarations.md`：按目标期刊实际要求填写声明；不得默认“无冲突”或“无需伦理审批”。
- `highlights.md`：仅当目标期刊要求时使用；条数和长度不以模板占位为准。

保留 TODO 表示待核实，不为使模板完整而猜测。实际投稿前核对原始要求、作者确认及最终提交文件。本目录不触发任何自动提交动作。
